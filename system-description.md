AI Loan Approval System (ALAS)
ALAS is a fictional machine learning system used by a bank to determine whether loan applicants should be approved or denied.

Inputs 
* Income
* Employment history
* Credit score
* Debt-to-income ratio
* Zip code

Outputs
* "Approved"
* "Denied"

Model Type 
Gradient Boosted Decision Trees (fictional) 

Purpose
Automate loan decisions to increase efficiency and reduce manual review
